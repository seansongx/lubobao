## 详细介绍

以下为 Markdown，整段粘贴到后台的介绍栏。只写不常变的内容：版本号、每版的变化写在更新说明里（发版时自动同步），安装和首次打开的步骤以官网为准，官网和源代码链接用后台的固定字段。新增平台或系统要求变化时再改这里。

---

录播宝是一个开源的直播录制工具。添加直播间后，它在后台定时检测，主播一开播就开始录制，下播后自动收尾，录像直接存进你的电脑，不经过任何服务器。

### 主要功能

- **开播自动录制**：定时检测，开播即录，下播收尾；断流后自动接着录。也可以只提醒开播、不录制。
- **直播间管理**：状态一目了然，支持筛选、搜索和批量操作。
- **分段录制，录后转 MP4**：中途断开不会丢掉已录的部分，录完自动转成 MP4。
- **录像库与动态**：按目录浏览录像，开播、录制和出错都有记录。
- **后台常驻**：关窗后收到托盘继续录制，退出前等文件写完。
- **自动安装组件，应用内更新**：FFmpeg 和新版本都校验后才安装。
- **服务器版**：另有无界面的命令行版和 Docker 镜像，适合放在服务器或 NAS 上长期运行。

### 支持的平台

抖音、快手，更多平台陆续接入。

### 系统要求

- Windows 10 / 11（64 位）
- macOS 10.15 及以后（Apple 芯片或 Intel 芯片）
- Linux x64 桌面；命令行版支持 x64 和 arm64

安装包暂未做代码签名，第一次打开时系统会提示来源未知，放行步骤见官网「首次打开」。

录播宝以 MIT 许可证开源，录制行为参考了开源项目 StreamCap，界面与实现为独立重写。

## 重新生成图片

在仓库根目录运行：

```powershell
npm run build
node docs/brand/xiaofany/capture.mjs
```

脚本用 `vite preview` 在 127.0.0.1:4180 提供正式构建（不占用 1420，正式构建的状态栏没有「调试」入口），再用无头 Edge（找不到时用 Chrome，也可用环境变量 `BROWSER` 指定）通过 DevTools 协议打开页面：

- 页面地址带 `?platform=windows&ffmpeg=ready`，浅色，窗口 1280×800、两倍像素；浏览器里不在 Tauri 中，自动使用 `src/lib/mock-api.ts` 的示例数据。
- 示例数据默认会在启动约 10 秒后弹出「发现新版本」对话框，脚本在每次页面加载后调用 `window.__lubobaoMock.setUpdate("none")` 关掉它；每次截图前还会检查页面上没有对话框、菜单、提示框或 toast，有就报错退出。
- 直播间页点选第一行「录制中」显示详情；录像库双击进入「抖音 / 一只小羊驼」；动态和设置直接打开。
- 每页的整窗图用 `gallery.html` 排版成 1600×1000 的 `gallery-*.png` 和 `gallery-*.webp`。
- 同一次运行还会更新官网的截图：`website/assets/rooms.webp`（首屏整窗，2560×1600）和四张局部放大图 `*-detail.webp`（裁剪区域写在脚本的 `websiteCrops` 里，界面布局变了要重新量）。调试时可以用环境变量 `CAPTURE_SOURCES` 指定一个目录，另存整窗原图。
- 封面先按 1280×800、两倍像素截一张不选中行的直播间页，再用 `cover.html` 排版成 1600×1000，同时输出 `cover.png` 和 `cover.webp`。
- 图标把 `docs/brand/app-icon.svg` 渲染成 256×256 透明底 PNG。

只依赖 Node 22 以上（内置 WebSocket）和本机的 Edge 或 Chrome，不需要额外安装 npm 包。示例数据里的时长、码率随时间变化，每次截图的数字会略有不同。
