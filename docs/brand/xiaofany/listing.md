## 详细介绍

以下为 Markdown，整段粘贴到后台的介绍栏。

---

录播宝是一个开源的直播录制工具。添加抖音、快手直播间后，它在后台定时检测，主播一开播就开始录制，下播后自动收尾，录像直接存进你的电脑，不经过任何服务器。

当前是 0.1 公测版，支持 Windows、macOS 和 Linux。

### 主要功能

- **开播自动录制**：按设定的间隔检测直播状态，开播即用 FFmpeg 开始录制，下播后自动收尾。断流后重新检测、接着录；手动停止的直播间保持停止，不会被重新拉起。也可以设为「仅通知」，只提醒开播不录制。
- **直播间管理**：每个直播间的状态一目了然，支持排序、筛选、搜索和多选批量暂停、恢复、删除；右侧详情显示当前录制和最近动态。
- **分段录制，录后转 MP4**：录制时按 TS 分段写入，中途断开也不会丢掉已录的部分。录完后逐个转成 MP4，默认保留原文件，转换失败时原文件不动。
- **录像库与动态**：在录像库里按目录浏览录像，用系统播放器打开或在文件夹中显示；动态页按时间记下开播、录制和出错，可按直播间和类型筛选。
- **后台常驻**：关闭窗口可以收到托盘，录制照常进行。开播和录制失败时发系统通知。有录制时退出会先确认，等文件写完再退出。
- **FFmpeg 自动安装，应用内更新**：第一次启动时在后台下载与系统匹配的 FFmpeg，校验通过后才安装，下载期间界面照常可用。新版本可以在应用内检查和安装，更新包校验签名后才装。
- **服务器版**：另有无界面的命令行版 `lubobao-cli` 和 Docker 镜像，和桌面版用同一套录制核心，适合放在 Linux 服务器、NAS 或容器里长期运行。

### 支持的平台

- **抖音**：直播间链接、抖音号、v.douyin.com 短链和主页链接都能识别。
- **快手**：支持 live.kuaishou.com/u/… 直播间链接，暂不支持 v.kuaishou.com 分享短链。

画质可选原画到流畅五档，所选画质取流失败时自动换一档。可以为平台设置代理和 Cookie。其他平台之后逐个接入。

### 系统要求

- Windows 10 / 11，64 位（x64）
- macOS 10.15 及以后，Apple 芯片或 Intel 芯片
- Linux x64 桌面（AppImage 或 deb）；命令行版支持 x64 和 arm64

### 第一次打开

安装包还没有代码签名，系统第一次打开时会提示来源未知，放行一次即可：

- **Windows**：出现「Windows 已保护你的电脑」时，点「更多信息」，确认是录播宝的安装程序后点「仍要运行」。
- **macOS**：推荐用官网的一键安装命令，不会被拦截。手动安装 dmg 时，macOS 15 及以后在「系统设置 → 隐私与安全性」底部点「仍要打开」；macOS 14 及更早在「应用程序」里按住 Control 点按录播宝，选「打开」。
- **Linux**：AppImage 先加上可执行权限再运行；deb 用 `sudo apt install ./lubobao_*.deb` 安装。

详细步骤见官网「首次打开」。

### 开源

录播宝以 MIT 许可证开源，录制行为参考了开源项目 StreamCap，界面与实现为独立重写。遇到问题欢迎到 GitHub 提 issue。

- 官网：https://lubobao.xiaofany.com
- 源代码：https://github.com/seansongx/lubobao

## 重新生成图片

在仓库根目录运行：

```powershell
npm run build
node docs/brand/xiaofany/capture.mjs
```

脚本用 `vite preview` 在 127.0.0.1:4180 提供正式构建（不占用 1420，正式构建的状态栏没有「调试」入口），再用无头 Edge（找不到时用 Chrome，也可用环境变量 `BROWSER` 指定）通过 DevTools 协议打开页面：

- 页面地址带 `?platform=windows&ffmpeg=ready`，浅色，窗口 1440×900；浏览器里不在 Tauri 中，自动使用 `src/lib/mock-api.ts` 的示例数据。
- 直播间页点选第一行「录制中」显示详情；录像库双击进入「抖音 / 一只小羊驼」；动态和设置直接打开。
- 封面先按 1280×800、两倍像素截一张不选中行的直播间页，再用 `cover.html` 排版成 1600×1000，同时输出 `cover.png` 和 `cover.webp`。
- 图标把 `docs/brand/app-icon.svg` 渲染成 256×256 透明底 PNG。

只依赖 Node 22 以上（内置 WebSocket）和本机的 Edge 或 Chrome，不需要额外安装 npm 包。示例数据里的时长、码率随时间变化，每次截图的数字会略有不同。
