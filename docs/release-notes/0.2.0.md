支持的平台从 2 个增加到 25 个，国内外主流直播平台基本都能录了。

- **新增 15 个国内平台**：B站、虎牙、斗鱼、小红书、YY、网易CC、微博、AcFun、花椒、映客、酷狗、六间房、百度、知乎、猫耳FM。
- **新增 8 个海外平台**：TikTok、Twitch、YouTube、SOOP（AfreecaTV）、CHZZK、TwitCasting、ShowRoom、17Live。在中国大陆需要在设置里开启代理，并把这些平台加入「走代理的平台」。
- **YouTube**：第一次检测到 YouTube 直播间开播时，会在后台自动下载录制所需的组件（yt-dlp 和 Deno，按固定的校验值核对后才安装），下载期间直播间显示进度。YouTube 常要求登录确认，建议在设置的平台账号里填写 YouTube Cookie。
- **粘贴更省事**：可以直接粘贴 App 里复制的整段分享文字，会自动找出其中的链接；新增支持 b23.tv、快手短链、快手和微博主页、小红书 rednote.com 等更多链接形式，重复添加的直播间也能认出来。
- **更稳定**：平台请求启用压缩并改进超时处理，网速慢时不再误报「解析失败」；单个任务出错不会影响其他正在录制的直播间；应用日志写入系统日志目录，方便排查问题。
- **界面**：左侧导航改为统一样式，长提示文字会自动换行。

成人、付费、密码或会员限定的直播间需要在设置里填写对应平台的 Cookie 才能录制。遇到问题欢迎到 GitHub 提 issue。
