录播宝首个公测版：开播自动录，不用再蹲直播。

- **抖音、快手**：粘贴直播间链接即可添加（抖音另支持抖音号、短链和主页链接），原画到流畅五档画质。
- **开播自动录制**：后台定时检测，开播即录，下播后收尾；断流后重新检测、接着录，手动停止的直播间不会被重新拉起。也可以设为「仅通知」，只提醒不录制。
- **直播间管理**：状态一目了然，支持排序、筛选、搜索和多选批量暂停、恢复、删除；右侧详情显示当前录制和最近动态。
- **分段录制，录后转 MP4**：TS 分段写入，录完逐个转成 MP4，默认保留原文件。
- **录像库与动态**：按目录浏览录像，用系统播放器打开或在文件夹中显示；动态按时间记录开播、录制和出错。
- **后台常驻**：关窗可收到托盘继续录制，有录制时退出先确认并等文件写完；开播和录制失败时发系统通知。
- **FFmpeg 自动安装**和**应用内更新**：都按固定的校验值或签名核对后才安装。
- 另有服务器用的命令行版 `lubobao-cli` 和 Docker 镜像。

这是公测版，安装包没有代码签名，第一次打开时系统会提示，按官网「首次打开」的步骤放行即可。遇到问题欢迎到 GitHub 提 issue。
